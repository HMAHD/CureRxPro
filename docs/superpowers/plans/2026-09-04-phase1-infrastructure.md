### Task 2: Switch CI workflows to Bun (#42 partial + #48)

**Files:**
- Modify: `.github/workflows/lint.yml`
- Modify: `.github/workflows/build.yml`
- Modify: `main.js` (platform detection for binary paths)

**Interfaces:**
- Produces: CI uses `bun install` / `bun run`; main.js binary paths work on macOS and Windows

- [ ] **Step 1: Update lint.yml — replace Node+npm with Bun, add PHP syntax check**

Replace the entire file content:
```yaml
name: Code Quality & Linting

on:
  push:
    branches: [ main, refactor/swe-remediation ]
  pull_request:
    branches: [ main ]

jobs:
  lint:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Setup Bun
        uses: oven-sh/setup-bun@v2
        with:
          bun-version: latest

      - name: Install Dependencies
        run: bun install

      - name: Run JavaScript Linter
        run: bun run lint

      - name: Check PHP Syntax
        run: |
          find . -name "*.php" \
            -not -path "./node_modules/*" \
            -not -path "./bin/*" \
            -exec php -l {} \;
```

- [ ] **Step 2: Update build.yml — replace Node+npm with Bun**

Replace the Node.js setup + npm ci + npm run steps:
```yaml
      - name: Setup Bun
        uses: oven-sh/setup-bun@v2
        with:
          bun-version: latest

      - name: Install Dependencies
        run: bun install

      - name: Build Desktop Application Executable
        run: bun run dist
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

(Remove the `setup-node` and `npm ci` / `npm run dist` steps.)

- [ ] **Step 3: Fix platform detection in main.js**

Find the binary path sections in `startMysqlServer()` and `startPhpServer()`. Currently they hardcode `.exe`. Replace with:

```js
const isWin = process.platform === 'win32';
const EXE = isWin ? '.exe' : '';
```

In `startMysqlServer()`, replace:
```js
// BEFORE
const mysqlBin = path.join(__dirname, 'bin', 'mysql', 'bin', 'mysqld.exe');
// AFTER
const mysqlBin = path.join(__dirname, 'bin', 'mysql', 'bin', `mysqld${EXE}`);
```

In `startPhpServer()`, replace:
```js
// BEFORE
const localPhp = path.join(__dirname, 'bin', 'php', 'php.exe');
if (fs.existsSync(localPhp)) {
  phpBin = localPhp;
} else if (fs.existsSync('C:\\xampp\\php\\php.exe')) {
  phpBin = 'C:\\xampp\\php\\php.exe';
}
// AFTER
const localPhp = path.join(__dirname, 'bin', 'php', `php${EXE}`);
if (fs.existsSync(localPhp)) {
  phpBin = localPhp;
} else if (!isWin) {
  // macOS/Linux: check Homebrew and system paths
  const macPaths = ['/opt/homebrew/bin/php', '/usr/local/bin/php', '/usr/bin/php'];
  phpBin = macPaths.find(p => fs.existsSync(p)) || 'php';
} else if (fs.existsSync('C:\\xampp\\php\\php.exe')) {
  phpBin = 'C:\\xampp\\php\\php.exe';
}
```

Also fix `mysqladmin.exe` in `gracefulCleanup()`:
```js
// BEFORE
const mysqlAdminPath = path.join(__dirname, 'bin', 'mysql', 'bin', 'mysqladmin.exe');
// AFTER
const mysqlAdminPath = path.join(__dirname, 'bin', 'mysql', 'bin', `mysqladmin${EXE}`);
```

Note: `isWin` and `EXE` must be declared at module scope (top of main.js, after the imports) so all three functions can access them.

- [ ] **Step 4: Verify main.js syntax**

```bash
node --check main.js
```

Expected: no output (no syntax errors).

- [ ] **Step 5: Commit CI + platform detection**

```bash
git add .github/workflows/lint.yml .github/workflows/build.yml main.js
git commit -m "$(cat <<'EOF'
fix(electron): add OS platform detection for MySQL and PHP binary paths

Windows-only .exe paths caused silent failures on macOS/Linux. Introduce
isWin/EXE constants at module scope; macOS falls back to Homebrew and
system PHP paths. Also switches CI workflows from npm to bun.

Closes #48
EOF
)"
```

### Task 3: Add PHPStan to CI (#42)

**Files:**
- Create: `composer.json`
- Modify: `.github/workflows/lint.yml` (add PHPStan step)
- Modify: `.gitignore` (add vendor/)

**Interfaces:**
- Produces: `composer install` installs PHPStan; `vendor/bin/phpstan analyse` runs level-5 check

- [ ] **Step 1: Create composer.json**

```json
{
    "name": "curerx/pro",
    "description": "CureRx Pro PHP backend",
    "require": {},
    "require-dev": {
        "phpstan/phpstan": "^1.11"
    },
    "autoload": {
        "psr-4": {
            "CureRx\\": "src/"
        }
    },
    "config": {
        "optimize-autoloader": true
    }
}
```

- [ ] **Step 2: Create phpstan.neon**

```neon
parameters:
    level: 5
    paths:
        - api
        - config
    excludePaths:
        - bin
        - node_modules
        - vendor
    ignoreErrors:
        - '#Call to function define\(\) with already defined constant#'
```

- [ ] **Step 3: Add vendor/ to .gitignore**

```
vendor/
```

- [ ] **Step 4: Add PHPStan step to lint.yml**

After the existing PHP syntax check step, add:
```yaml
      - name: Install Composer Dependencies
        run: composer install --no-interaction --prefer-dist --optimize-autoloader

      - name: Run PHPStan Static Analysis
        run: vendor/bin/phpstan analyse --no-progress
```

Also add PHP setup step before the Bun setup (ubuntu-latest has PHP but may need specific version):
```yaml
      - name: Setup PHP
        uses: shivammathur/setup-php@v2
        with:
          php-version: '8.1'
          tools: composer
```

- [ ] **Step 5: Run PHPStan locally to verify zero errors**

```bash
composer install && vendor/bin/phpstan analyse --no-progress 2>&1 | tail -5
```

Expected: `[OK] No errors` or a count of errors to triage. If errors found, add them to phpstan.neon `ignoreErrors` with inline comment explaining each one — only pre-existing issues that are out of Phase 1 scope.

- [ ] **Step 6: Commit**

```bash
git add composer.json phpstan.neon .gitignore .github/workflows/lint.yml
git commit -m "$(cat <<'EOF'
chore(ci): add PHPStan level-5 static analysis to CI lint job

Installs phpstan/phpstan via Composer require-dev. CI runs analyse
on api/ and config/ directories. Pre-existing errors from phases
not yet refactored are suppressed with inline comments in phpstan.neon.

Closes #42
EOF
)"
```
